# 🐂 OMBILAHY Stock & Inventory Management System

Une application web de gestion de stock du societe OMBILAHY  
Elle permet de gérer efficacement les matières premières, les produits finis, les mouvements de stock.

---

## 📌 Overview

Ce projet vise à fournir une interface moderne, responsive et performante pour :

- 📦 Gestion des matières premières
- 🏭 Gestion des produits finis
- 🔄 Suivi des mouvements de stock
- 📊 Tableau de bord analytique

---

## 🛠 Tech Stack

- **HTML5**
- **TailwindCSS v4**

---

## ⚙️ Project Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/OMBILAHY.git
cd OMBILAHY
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start development mode

```bash
npm run dev
```

Tailwind will watch for changes and generate `output.css` automatically.

---

## 🏗 Production Build

To generate a minified CSS file for production:

```bash
npm run build
```

---
---

## 🧩 NPM Scripts

```json
"scripts": {
  "dev": "tailwindcss -i ./input.css -o ./output.css --watch",
  "build": "tailwindcss -i ./input.css -o ./output.css --minify"
}
```

---

## ⚠️ Important Notes

- Do not edit `output.css` manually.
- All style modifications must be done in `input.css`.
- `node_modules` is excluded from version control.
